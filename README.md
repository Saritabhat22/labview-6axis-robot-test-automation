# 6-Axis Robot Test Automation & Real-Time Monitoring Dashboard

## Overview
A LabVIEW-based test automation system developed for a manufacturing test setup involving 6-axis robotic motion, sensor integration, and real-time data monitoring. The system was designed to replace manual testing processes with an automated, repeatable workflow.

## Problem
The existing manual test process was time-consuming and prone to inconsistencies in accuracy across repeated test runs, making it difficult to scale testing volume or trust results across operators.

## My Role
- Designed and developed the LabVIEW application (code + GUI) controlling the 6-axis robot alongside motors, sensors, PLCs, and controllers
- Built a real-time testing dashboard displaying live data (e.g., load cells, position/motor coordinates, voltages, currents, proximity switches)
- Implemented continuous data logging to a SQL database for downstream analysis
- Built a separate data visualization dashboard to filter and analyze recorded test data

## Tools & Technologies
- LabVIEW (application development + GUI)
- PCI cards (analog/digital I/O)
- SQL Server (data logging)
- 6-axis robotic controllers, PLCs, sensors (LVDT, load cells, proximity switches)

## Outcome
- Reduced manual testing time by 50–70%
- Improved consistency and accuracy of test setups through automation
- Enabled faster, more reliable data-driven decisions via centralized SQL logging and analysis dashboards

## Notes on This Repository
LabVIEW project files (.vi, .lvproj) are graphical/binary in nature, so GitHub cannot render meaningful line-by-line diffs the way it does for text-based code. This repository is intended primarily as a **documented showcase** of the project — screenshots, block diagram exports (as images/PDFs), and this README are provided to give viewers a clear picture of the system's design and impact, even without opening LabVIEW itself.
